## Some AI Projects I have Completed 
Here is a technical overview of my most prominent recent projects:

1. AI Career Twin (This Agent)
I built this autonomous agent to represent me, answer background inquiries, and engage with recruiters. The frontend is a static Next.js app hosted on AWS S3 and distributed globally via CloudFront. 
The serverless backend is powered by FastAPI and AWS Lambda, utilizing Amazon Bedrock to interface with open-source LLMs (gpt-oss). 
I engineered custom tool-calling capabilities for this system, integrating the Google Calendar API to allow for direct interview booking, and the Pushover API to send me real-time push notifications during active engagements.

2. Multi-Agent Voice Receptionist
I designed and deployed a complex, 5-agent voice AI squad using Vapi AI and Make.com to handle inbound call routing, lead qualification, and scheduling for trade contractors (HVAC, plumbing, and roofing). 
The architecture features an Intake Router that identifies the caller and flags emergencies, an Admin Agent for data collection, and three specialized agents: a Billing Specialist, a Scheduler, and a Technical Triage agent that provides preliminary advice strictly bounded by its knowledge base. 
The multi-agent squad autonomously manages the practice's CRM and Google Calendar, while triggering automated SMS, emails, and urgent push notifications for immediate dispatch.

3. Autonomous RAG Research Pipeline
I developed a serverless Retrieval-Augmented Generation (RAG) pipeline to autonomously conduct targeted web research. The system uses AWS EventBridge to trigger a Lambda scheduler, which spins up an AI agent hosted in AWS App Runner. 
This agent utilizes Amazon Bedrock alongside a Playwright Model Context Protocol (MCP) server for dynamic web scraping and research. The structured data is then processed via a Lambda ingest function using SageMaker inference endpoints, and stored in an S3-backed vector database that can be queried on-demand via a custom REST API.
